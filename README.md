
# COMPUTER ARCHITECTURE

A university group project developed for **[COMPUTER ARCHITECTURE]** at TAR UMT.

## Project Information

- **Programme:** Diploma in Information Technology
- **Year / Semester:** Y1S2

## Overview

GradePoint is a DOS-based student grade and GPA calculator developed in 16-bit x86 assembly language. Users can log in, enter a student's name and marks for selected subjects, and convert the marks into letter grades and grade points. The program calculates the student's GPA and total credit hours, and also provides a grade-point reference list for viewing.

## Features

- Login authentication with a predefined username.
- Enter marks for up to nine subjects, including Mathematics, Physics, Chemistry, History, English, Biology, Computer Science, Economics, and Geography.
- Convert marks into letter grades and grade points based on the programmed grading scale.
- Calculate and display the student's GPA and total credit hours.
- View the grade and percentage-range reference list.
- Navigate back, log out, or exit the program through the menu options.
